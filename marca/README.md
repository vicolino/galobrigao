# 📁 marca/ — Manual da Marca Galo Brigão

Tudo que define a identidade visual do **Galo Brigão** (*Chicken Fighter*) num lugar só.

## O que tem aqui

| Arquivo | O que é |
|---|---|
| **`manual-da-marca.html`** | Manual visual completo — **abra no navegador** (clique duas vezes). |
| `manual-da-marca.md` | Mesma coisa em texto, fácil de editar. |
| `assets/mascote-galo-brigao.svg` | Mascote oficial (Galo de Ouro, pena de fogo, coroa). Vetor. |
| `assets/skin-ouro.svg` · `skin-galaxia.svg` · `skin-neon.svg` | Variações de skin do mascote. |
| `assets/galo-conjunto-dragao.svg` | Galo equipado com o conjunto Fúria do Dragão. |
| `assets/avatar-instagram-1080.png` | Foto de perfil pronta (1080×1080) para redes sociais. |
| `assets/cores.css` | Tokens de cor em CSS (`:root`) — cole e reaproveite. |
| `assets/tokens.json` | Marca, fontes e cores em JSON (para ferramentas/código). |

## Atalhos

- **Nome:** Galo Brigão (🇧🇷) / Chicken Fighter (🌎)
- **Cor principal:** Sol `#ff9f1c`
- **Fontes:** Lilita One (títulos) + Nunito (texto)
- **Tagline:** *Crie seu galo, treine, vista e domine a arena.* 🌽
- **Site:** galobrigao.com.br

As artes vêm do próprio jogo, então o manual é fiel ao que o jogador vê na tela.
